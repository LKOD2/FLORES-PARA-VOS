# Flores para vos

La idea surgió por olvidar comprar flores amarillas el día de la primavera.
Así nació esta página para escribirle un mensaje bonito a esa persona que te gusta y regalarle flores amarillas.

Se puede elegir un diseño y compartirlo con un código QR. Es 100% estática (sin servidor ni base de datos): el mensaje viaja codificado en la propia URL.

Construida con React + Vite.

## Uso en local

```bash
npm install
npm run dev
```
